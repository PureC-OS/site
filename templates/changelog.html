What is new in
PureC OS.

Highlights of the current release. The complete, detailed log lives in the repository.

v1.2.28current

Accounts, new installer, RNG driver and a VFS mount table

Desktop

  • Application icons from one consistent Material Symbols set, rasterized at build time and tinted for contrast on each tile
  • Icon grid with snap-to-cell dragging, a drop preview frame and a layout saved between sessions
  • Interface scale from 100% to 400% and a terminal font size you can change in Settings

Installer

  • Fully rewritten as a graphical wizard: Welcome, Disk, Computer, Account, Review and Install
  • Anti-aliased rounded shapes, gradients and shadows drawn in its own buffer with no flicker
  • Disk cards with model, size and bus type, plus a partition layout preview

Graphics and input

  • Double-buffered compositor: windows no longer show half-drawn frames while moving
  • Live resolution switching on VMware SVGA II, as used by VirtualBox
  • Absolute mouse pointer in VirtualBox, so the cursor never drifts from the host
  • Fixed a deadlock that froze the system after dragging a window

Kernel and IO

  • Storage drivers moved into a new IO subsystem with an IO scheduler and background QoS
  • Installation and swapping no longer freeze the interface
  • Permissions and accounts, an RNG driver, ext2 without stubs and a mount-table VFS

The full history is on GitHub.
