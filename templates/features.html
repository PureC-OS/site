// the details

What you get out of the box.

⚙

Kernel

  • SMP with per-core scheduling
  • Copy-on-write fork and execve
  • Pipes and POSIX-style signals
  • ACPI: shutdown and reboot
▤

Storage

  • AHCI and ATA PIO drivers
  • Mount-table VFS
  • Full ext2, no stubs
  • IO scheduler with background QoS
◧

Graphics

  • GOP, VBE and VMware SVGA II
  • Live resolution change
  • Interface scale 100–400%
  • Flicker-free compositor
⌨

Input

  • PS/2 keyboard and mouse
  • USB mouse via xHCI and EHCI
  • VirtualBox absolute pointer
  • I2C-HID touchpad groundwork
⇄

Networking

  • Intel PRO/1000 82540EM, 82543GC
  • AMD PCnet-PCI II
  • Atheros AR9285 port in progress
  • 802.11 association
#

Security

  • Users, groups and permissions
  • SHA-512 password hashing
  • Own RNG driver
  • Login screen and login gate
