From git clone
to a booted desktop.

PureC OS is built from source. You need a Linux host, a C toolchain, NASM, Limine and an x86_64-elf cross compiler.

Install the toolchain

Pick your distribution. A cross compiler for x86_64-elf is required.

sudo apt update sudo apt install make gcc g++ limine nasm xorriso mtools # cross compiler: build binutils + gcc for x86_64-elf # (full recipe in the README)
sudo dnf update --refresh sudo dnf install make gcc g++ limine nasm xorriso mtools # cross compiler: build binutils + gcc for x86_64-elf # (full recipe in the README)
sudo pacman -S --needed base-devel git make gcc limine nasm # cross compiler from the AUR yay -S x86_64-elf-gcc x86_64-elf-binutils

Clone and build

The Python build script fetches the extra components (ACPI, crypto, TinyCC, userspace) automatically and produces the ISO.

git clone https://github.com/PureC-OS/PureC-OS.git cd PureC-OS python purec.py

Boot it

Create a VM in VirtualBox or QEMU, attach the built ISO and start it. VirtualBox gives you the absolute mouse pointer and the Intel e1000 network card.

Choose Install on the desktop to run the graphical installer and put PureC OS on a disk.

What it was built with.

Toolchain

  • GCC and G++ 16.2
  • x86_64-elf cross GCC 15.2
  • NASM 3.02
  • GNU Make 4.4.1
  • Limine 12.8

Supported virtual hardware

  • VirtualBox 7.2 and QEMU
  • Intel PRO/1000 MT Desktop 82540EM
  • Intel PRO/1000 T Server 82543GC
  • AMD PCnet-PCI II (Am79C970A)
