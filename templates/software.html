PureC OS ships a hosted libc, libm and a dynamic loader. That is enough to bring serious software over. Here is what works today and what is still in progress.

SoftwareVersionLicenseStatusNotes
Lua5.4.8MITworkingFull REPL with line echo. math library comes next now that libm has landed.
MicroPython1.30MITworkingInteractive REPL, no floats yet.
TinyCC0.9.28rcLGPL-2.1workingCompile and run C programs on the OS itself.
SDL22.33.0zlibworkingSoftware rendering. Includes an in-house SDL2_mixer shim with an OPL hook.
Chocolate Doom3.1.1GPL-2.0workingDoom only, no netplay. Plays with Freedoom 0.13.0 assets.
Vim9.2Vimin progressBuilds and links with tiny features. Terminal layer is ready, not yet run on PureC OS.
GNU Make4.4.1GPL-3.0+in progressStarts and reports its version. Makefile runs not verified, single job only.
